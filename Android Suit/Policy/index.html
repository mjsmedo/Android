Android Suit — Privacy Policy

Effective date: 9 November 2026

Android Suit is a file & storage toolkit for Android — it finds duplicates, cleans junk, renames files, analyzes storage, removes image backgrounds, edits file timestamps, creates and extracts archives, encrypts files, generates and scans QR codes, reports device and memory information, and manages installed apps. This policy explains what the app can access and what happens to it. The summary is simple: your data never leaves your device.

Data the app accesses

Files on shared storage (All files access). The tools use the MANAGE_EXTERNAL_STORAGE permission to read and organize files across your device's shared storage — that is what a duplicate finder, junk cleaner, renamer, space analyzer, image editor and timestamp tool do. Files are only read or modified when you run a tool and act on the results. The app never uploads or copies your files anywhere.

Installed apps. The App Manager lists the apps installed on your device so you can open their system settings or uninstall them. It does not use QUERY_ALL_PACKAGES; it declares a narrow <queries> entry that returns only apps with a launcher icon — the ones you can already see and open yourself. It reads only app names, package identifiers, and — if you grant the optional Usage access (PACKAGE_USAGE_STATS) — their storage sizes and when they were last used. This information is shown to you and is never transmitted or stored off-device. Uninstalling is performed by Android's own system dialog (REQUEST_DELETE_PACKAGES); the app cannot remove anything without your confirmation.

Camera. The QR Code tool can scan a code with the camera (CAMERA). The preview is processed on your device as it arrives, purely to decode whatever code is in frame. No photo or video is recorded, saved or transmitted. The permission is requested only when you start a scan, and the tool still works without it — you can decode a QR code from an image file instead.

Device and storage information. System Info, Memory and Storage Speed read values your device already publishes about itself — total and free storage, memory in use, battery and hardware details — through Android's own APIs and public system files. These figures are displayed to you and nothing more. The dashboard also keeps a local tally of what the tools have done, so it can show you how much space they have reclaimed.

Accessibility service (Force Stop)

The Force Stop tool uses an Android accessibility service. This section explains it in full, because it is the most capable permission the app asks for.

What it does. Android does not let one app stop another, so Force Stop does what you would do by hand: it opens the App info screen for each app you selected, presses that screen's Force stop button, and confirms the dialog — one app after another, while you watch every step happen on screen. It follows a fixed sequence of steps. It makes no decisions of its own, and it never acts on an app you have not chosen.

What it can see. An accessibility service is able to read what is on screen. This one reads screen content only in the system Settings app, only while a run that you started is in progress, and only to locate that button and its confirmation. It does not read any other app, and it does not run at any other time.

What happens to that. Nothing is recorded, nothing is stored, and nothing is transmitted. The service keeps no log of what it saw. Its only output is the number of apps stopped, which the app shows you when the run finishes.

You turn it on, and you can turn it off. The app explains all of the above inside the app and asks you to accept it before it will even send you to Android's accessibility settings. If you decline, nothing is enabled and the rest of the app works normally. You can switch the service off at any time in Settings → Accessibility, and Android itself revokes it if you force-stop Android Suit.

It is not an accessibility tool. Android Suit is a file and storage toolkit, not an aid for people with disabilities, and it does not claim to be one — it does not set the isAccessibilityTool flag. It uses the accessibility API for the single automation task described above, and declares that use honestly.

Notifications

The app posts no notifications. It asks for POST_NOTIFICATIONS for one indirect reason: Android suppresses a background app's brief pop-up messages while that permission is denied, which left the Force Stop home-screen widget finishing a run without telling you the result. The permission is only requested if you want that pop-up, and the widget writes the result on itself either way.

Data the app stores

Your settings, per-tool preferences, and the in-app Trash are stored locally in the app's own storage. Deleting files with Trash enabled moves them to a hidden folder on your own device until the retention window expires. Uninstalling the app removes its settings and empties its Trash.

Data the app shares

None. Android Suit has no INTERNET permission and contains no networking code. It cannot and does not transmit any data off your device. There are no analytics, no advertising SDKs, no crash-reporting services, and no user accounts. This applies to everything described above without exception, including anything the accessibility service sees.

The only way data leaves the app is when you explicitly move, export, or share a file yourself.

Children

The app does not knowingly collect any data from anyone, including children, because it collects no data at all.

Changes to this policy

If a future version of the app changes any of the above, this page will be updated and the effective date revised before that version is released.
